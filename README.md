# Lashflow Studio Manager

Desenvolvimento de Aplicativo de Gestão para Lash Designer



Desenvolver um aplicativo moderno, intuitivo e responsivo, exclusivo para Lash Designers, com o objetivo de centralizar o gerenciamento de agenda, clientes, procedimentos e financeiro.



O aplicativo deverá possuir uma interface elegante, minimalista e sofisticada, com navegação simples e otimizada para celulares.



Funcionalidades obrigatórias:



1. Dashboard com resumo dos atendimentos do dia, próximos horários e faturamento.

2. Agenda interativa com visualização diária, semanal e mensal.

3. Cadastro de agendamentos com nome da cliente, telefone, data, horário, procedimento, duração, valor, sinal, forma de pagamento e observações.

4. Cadastro individual de clientes com histórico completo de atendimentos.

5. Cadastro e gerenciamento de procedimentos, modelos de cílios, preços e duração.

6. Controle financeiro com receitas, despesas, pagamentos pendentes e relatórios.

7. Notificações e lembretes de agendamentos e manutenções.

8. Controle de cancelamentos, faltas e remarcações.

9. Galeria de fotos vinculada ao histórico de cada cliente.

10. Relatórios de desempenho e faturamento.

11. Integração com WhatsApp para facilitar a comunicação.

12. Sistema de backup e armazenamento seguro dos dados.



Requisitos técnicos:



- Aplicativo adaptado para Android e iOS.

- Interface responsiva.

- Banco de dados para armazenar clientes, agendamentos e informações financeiras.

- Sistema de autenticação e proteção dos dados.

- Sincronização das informações.

- Possibilidade de expansão futura com novas funcionalidades.



Objetivo final: criar uma ferramenta completa de gestão para Lash Designers, que substitua agendas tradicionais e planilhas, tornando a rotina profissional mais organizada, eficiente e lucrativa.
